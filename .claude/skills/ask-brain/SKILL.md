# Ask the brain

1. Search the vault for the question's key terms and synonyms: frontmatter (`industries`, `risks`, `use_cases`, `keywords`, `state`), headings and body. Check `places/`, `use-cases/`, `seo/`, `ideas/`, then `inbox/`.
2. Follow `[[links]]` one step from each hit to pick up related notes.
3. Answer from the notes only. After each fact, cite the note as `[[note-name]]`, and its original source if the note gives one.
4. End with **Gaps**: what the vault does not cover. Offer `/research-place` or a search for each gap. Do not fill gaps from memory.
5. If the answer connects ideas that are not linked yet, offer to add the links.
